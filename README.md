## Завдання до дипломної роботи
Розроблений програмний продукт має являти собою сайтвізитку. Він має надавати всю необхідну функціональність: інтуїтивнозрозумілий інтерфейс, можливість перегляду інформації про послугиготелю, можливість онлайн чату. Розробку виконати мовою JavaScript

## Використані технології

- **HTML5** — створення структури вебсайту та сторінок.
- **CSS3** — оформлення дизайну, стилізація елементів та адаптивність сайту.
- **JavaScript (ES6)** — реалізація інтерактивності та динамічних елементів.
- **Flexbox** — побудова адаптивного розташування блоків.
- **CSS Grid Layout** — створення галереї та сіткових елементів.
- **Media Queries** — адаптація сайту під мобільні пристрої та планшети.
- **CSS Animations & Transitions** — анімації, ефекти наведення та плавні переходи.
- **3D Transformations (CSS3)** — створення 3D-каруселі послуг.
- **Font Awesome** — використання іконок для інтерфейсу сайту.
- **Google Maps Embed API** — інтеграція карти на сторінці контактів.
- **Responsive Web Design (RWD)** — забезпечення коректного відображення сайту на різних пристроях.
